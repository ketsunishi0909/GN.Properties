# G.N Properties

Production website for **G.N Properties**, a Delhi-NCR real-estate consultancy serving clients across Rohini, Delhi, Gurgaon, and Noida.

## Overview

I built this website for my father's real-estate business to create a professional online presence and make it easier for prospective clients to discover services, understand the firm's coverage, and contact the business directly.

## What the Site Includes

- Responsive real-estate landing page
- Buy / sell / rent service positioning
- Delhi-NCR locality coverage
- Direct call and WhatsApp actions
- English/Hindi-friendly interface structure
- Search-engine metadata and canonical URL
- Open Graph / social sharing metadata
- Schema.org `RealEstateAgent` structured data
- Local-business location and contact metadata

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- JSON-LD structured data
- Responsive web design

## Production

**Website:** https://www.gnproperties.in/

## Local Development

This is a lightweight static site with no required build process.

```bash
git clone https://github.com/ketsunishi0909/GN.Properties.git
cd GN.Properties
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Why I Built It

This project was built for a real business rather than as a classroom exercise. The goal was to create a clean, credible, mobile-friendly web presence while also improving discoverability through technical SEO, structured data, and local-business metadata.
